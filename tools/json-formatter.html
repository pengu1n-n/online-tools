О инструменте

Форматтер расставляет отступы и переносы, чтобы структуру данных было удобно читать. Опция минификации, наоборот, убирает все лишние пробелы — это полезно для API и конфигов.

Если в JSON есть ошибка, инструмент покажет сообщение браузера с указанием проблемного места. Исправьте его и повторите операцию.

Частые вопросы

Что такое минификация JSON?

Это удаление пробелов и переносов строк без изменения данных. Такой файл занимает меньше места.

Можно ли форматировать JSON с кириллицей?

Да, кириллица и эмодзи сохраняются без искажений.

Нужно ли регистрироваться?

Нет. Инструмент полностью бесплатный и работает в браузере.
