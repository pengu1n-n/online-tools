О инструменте

Инструмент поддерживает большие числа благодаря BigInt, поэтому можно переводить даже очень длинные значения без потери точности.

Допустимые префиксы: 0b для двоичной, 0o для восьмеричной и 0x для шестнадцатеричной системы. Пробелы и подчёркивания игнорируются.

Частые вопросы

Как ввести отрицательное число?

Начните число со знака «−» — результат тоже будет отрицательным.

Есть ли ограничение на размер?

Практически нет: используется BigInt. Ограничением является только память браузера.

Можно ли копировать результаты?

Да, у каждого значения есть кнопка «Копировать».
